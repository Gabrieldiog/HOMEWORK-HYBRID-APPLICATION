# Semestre

Aplicativo híbrido para organizar as matérias do semestre, com provas, trabalhos e atividades por prazo. Feito com Ionic + React e Capacitor.

## Rodando

```bash
npm install
npm run dev
```

## Stack

- Ionic 8 + React 18
- React Router 5 (via `@ionic/react-router`)
- Capacitor 7 com `@capacitor/preferences` para salvar os dados no dispositivo
